# stock-trading-tracker
A simple Java console-based Stock Trading Platform built using Object-Oriented Programming (OOP). Users can view available stocks, buy and sell shares, manage a portfolio, and track wallet balance through a menu-driven interface. Developed to strengthen Java fundamentals and problem-solving skills.
